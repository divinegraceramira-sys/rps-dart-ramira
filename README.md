## Description

This is a two-player Rock, Paper, Scissors console game written in Dart. Players enter their moves, the program determines the winner of each round, tracks the scores, and announces the overall winner.

## Requirements

- Dart SDK installed
- VS Code or Command Prompt

## How to Run

1. Open the project folder in VS Code.
2. Open the terminal in the project folder.
3. Run the following command:

   ```bash
   dart rock_paper_scissors.dart
   ```

4. Enter the names of both players.
5. Enter `rock`, `paper`, or `scissors` when prompted.
6. Follow the prompts to play again or finish the game.

## Features

- Two-player gameplay
- Input validation
- Null safety
- Round winner and draw detection
- Score tracking
- Play-again option
- Final score and overall winner announcement
